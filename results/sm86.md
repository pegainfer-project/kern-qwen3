# RTX 3090 startup and numerical validation

Validated on one RTX 3090 (SM86) with driver 595.58.03 and Qwen3-4B BF16
weights. All eight `sm_86` cubins were built with CUDA 13.2.51. The CLI and
`kern-llm` wheel came from kern revision
`86e761aca2118bbe5b5f9dc6e5156f86894a428d`. The numerical checks used PyTorch
2.13.0+cu130 and Transformers 5.17.0.

## Startup

Using the same cubins, the previous runtime pin `248e7aa` failed in
`cuModuleLoadData(signals)` with `CUDA_ERROR_INVALID_PTX`. The upgraded runtime
rejected the old manifest because `decode` and `decode_batch` both take one row
per sequence. The regenerated manifest passed verification at `max-seqs=1` and
`32`. With the default bundle, a single-sequence `kern run` completed prefill
and generated eight tokens using CUDA Graph decode.

After installing the pinned runtime and initializing the submodules as shown in
the [build instructions](../README.md#build-and-generate), run the SM86 smoke test.

```sh
uv run python scripts/build.py --sm sm_86 --nvcc /usr/local/cuda-13.2/bin/nvcc
uv run python scripts/gen.py --checkpoint /path/to/Qwen3-4B \
  --kernels build/sm_86 --out out/qwen3-sm86
kern verify out/qwen3-sm86/model.json
kern run --config out/qwen3-sm86/kern.toml \
  --prompt 'The capital of France is' --steps 8 --capacity 1024
```

## Numerical results

- `scripts/accuracy.py` passed all eight Transformers cases across four prompts
  and prefill chunk sizes 16 and 256. The highest mean KL across cases was
  0.00117 against a 0.01 threshold. Top-1 agreed on 62 of 64 decode steps.
- `scripts/batch_check.py` passed at 1, 3, 17, and 32 sequences. The largest
  per-sequence KL was 0.00247. Seeded sampling at 32 sequences replayed exactly.
- All three GPU tests passed, covering attention against PyTorch SDPA, sampling
  filters and distribution, and CUDA Graph replay.
- The benchmark planner kept both smoke and all four attention prefill scenarios.
